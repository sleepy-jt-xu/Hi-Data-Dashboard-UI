# 页面生成质量检查清单

输出前逐项检查。标记为“不适用”的项目需有明确原因。

## 业务与信息

- [ ] 页面服务的用户和决策任务明确。
- [ ] 核心指标、维度、时间范围和统计口径明确。
- [ ] 页面模式符合主要任务。
- [ ] 信息顺序支持从概览到分析或行动。
- [ ] 页面没有无业务目的的指标、图表或装饰。

## 数据表达

- [ ] 图表类型符合数据关系和分析目的。
- [ ] 坐标轴、单位、图例、标签和 Tooltip 足以正确理解数据。
- [ ] 数字精度、缩写、正负值、零值和缺失值表达一致。
- [ ] 示例数据的合计、比例和趋势关系自洽。
- [ ] 颜色不是区分状态或系列的唯一手段。

## 布局与视觉

- [ ] 页面使用已确认的 Token 和组件规则。
- [ ] 标题、摘要、分析和明细层级清晰。
- [ ] 对齐、间距、密度和容器关系一致。
- [ ] 主要操作与次要操作容易区分。
- [ ] 使用的图标来自已确认图标库，且语义、尺寸和状态一致。
- [ ] 仅靠图标难以理解的操作提供文字、Tooltip 或可访问名称。
- [ ] 页面在目标画布或设备上没有关键内容溢出。

## 交互与状态

- [ ] 筛选的作用范围和生效方式清楚。
- [ ] 下钻、返回、刷新和导出的行为清楚。
- [ ] 已判断加载、空、无结果、错误、无权限和数据过期状态是否适用。
- [ ] 错误或空状态提供合理的下一步。
- [ ] 权限和敏感信息符合要求。

## 可访问性与实现

- [ ] 文字和关键视觉元素具有足够对比度。
- [ ] 键盘焦点、可点击区域和状态反馈可识别。
- [ ] 图表有替代说明或可访问的数据途径（适用时）。
- [ ] 方案可以由目标技术实现，没有依赖未说明的能力。
- [ ] 待确认规则和设计假设已在交付中列出。
