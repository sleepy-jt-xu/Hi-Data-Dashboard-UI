# 页面模板

> 当前状态：6 个页面模板已确认。生成页面时优先选用最接近的模板；都不适用时，参考文末「其他页面类型」组合已有组件，并在交付说明中写明理由。

## 已确认的页面模板

以下模板已在 HTML 规范站「页面模板」中提供可交互预览。所有模板共用：标题栏（Logo + Page Title + 说明/导出图标，高 `50px`）、筛选栏（Time Filter Tag + 7 个 Dropdown）；页边距 `32px`，容器之间 `16px`，容器内边距 `20px`。

| 模板 | 结构 | 适用场景 |
|---|---|---|
| 报表模板1 | 标题栏 → 筛选栏 → Tabs → Dimension & Metric（Radio 币种、Checkbox 维度与指标）→ Report Table（合并单元格 + Total 行） | 多级维度汇总报表 |
| 报表模板2 | 标题栏 → 筛选栏 → Dimension & Metric（Row / Column / Metric 选择按钮）→ 明细表 | 自定义行列透视报表 |
| 数据看板模板1 | 标题栏 → 筛选栏 → 指标卡（白底，独立成卡，间距 `16px`）→ 左：组合图 + 单色环形图 + 环形图；右：门店明细表 | 同时纵览多项指标，图表与指标卡相互独立 |
| 数据看板模板2 | 标题栏 → 筛选栏 → 一个容器内：指标卡（灰底 `#F7F8FA`，间距 `12px`）+ 可切换指标的簇状柱状图 → 门店明细表 | 围绕少数指标深入查看，指标卡与图表同属一个分析区 |

| 数据看板模板3 | 标题栏 → 筛选栏（Time 含周选择）→ Tabs → 一个容器内按分类分组的主要指标卡（Sell out / Store / Inventory，各用分类底色，组标题 H2）→ 左：组合图 + 折线图；右：门店明细表 | 主要指标较多，需要分类展示 |
| 数据看板模板4 | 标题栏 → 筛选栏（Time 含周选择）→ 一个容器内：一行主要指标卡 + 三组二级指标-横向列表 → 左：组合图 + 折线图；右：门店明细表 | 同时展示主要指标和次要指标 |

### 页面背景（按场景）

| 场景 | 页面背景 |
|---|---|
| 常规（默认） | 纯色 `#F2F3F5` |
| 数字化门店 | 渐变背景图 `assets/digital-store-bg.png`（1920 × 1080），铺满页面、顶部对齐 |

- 两种场景下容器、卡片、组件样式不变，只替换页面背景。
- 用户未说明场景时使用常规。

### 数据看板模板3 与 4 的区别

- **模板3**：只有主要指标，按业务分类分组，每组有组标题，卡片使用对应的分类底色（`#E7F4F9` / `#E5EEFC` / `#F7F1E8`）。
- **模板4**：区分主次。主要指标卡一行展示，次要指标用「二级指标-横向」列表放在主要指标下方，与主要指标同属一个容器。

### 数据看板模板1 与 2 的区别

- **卡片层级**：模板1 的指标卡是独立的白色容器，放在灰色页面背景上；模板2 的指标卡是灰底卡片，和图表一起放在同一个白色容器内。
- **与图表的关联**：模板1 的图表各自成卡，与指标卡平级、互不联动；模板2 的柱状图用 Filter Tag 切换 Sell out Unit / Sell out Amount，和上方指标卡属于同一分析区。

## 其他页面类型（参考，非正式模板）

### 1. 总览报表

适合快速掌握整体状态、关键变化和异常。参考结构：全局筛选、核心指标、主要趋势、构成或排名、异常与明细入口。

### 2. 趋势分析页

适合观察指标随时间变化并比较周期或分组。参考结构：指标与时间控制、主趋势图、同期对比、影响因素和明细。

### 3. 多维分析页

适合按多个维度切片、比较和下钻。参考结构：分析条件、维度/指标配置、可视化区、透视表和已选路径。

### 4. 明细查询页

适合定位记录、执行筛选、查看详情和导出。参考结构：筛选区、结果摘要、数据表、分页、列设置和批量操作。

### 5. 排名与对比页

适合比较对象表现、识别领先和落后项。参考结构：范围选择、排名摘要、条形或点图、差异解释和明细表。

### 6. 漏斗或流程分析页

适合分析阶段转化、流失和路径。参考结构：范围筛选、总转化、阶段图、分群对比、流失定位和明细。

### 7. 实时监控页

适合持续观察及时性强的指标和异常。参考结构：状态栏、实时指标、时序变化、告警、事件流和刷新说明。

## 模式选择原则

- 以用户要做的判断和动作选择模式，不以页面看起来像什么选择。
- 一个页面应有一个主要模式；其他模式只能作为辅助区块。
- 内容过多时优先拆分任务，不默认把所有图表塞进总览页。
- 新模式进入正式规范前，至少要说明它与现有模式的差异和必要性。
